## Project Overview

This project contains three simple, responsive website concepts created as web activity-based programs. Each website demonstrates a different real-world use case and includes structured sections, navigation, cards, and forms.

## 1. Healthy Food & Nutrition Website

**Purpose:** To promote healthy eating habits and provide visitors with simple nutritious meal ideas.

### Main Features
- Header and navigation menu
- Food categories, including vegetables, fruits, and whole grains
- Healthy recipe cards with ingredients, preparation steps, and estimated calories
- Daily meal plan covering breakfast, lunch, an evening snack, and dinner
- Healthy eating tips
- Footer with website copyright information

## 2. Grand Stay Hotel Website

**Purpose:** To present hotel accommodation options and provide a sample room-reservation interface.

### Main Features
- Hotel landing page with a booking call-to-action
- Room reservation form with check-in/check-out dates, guest count, and room category
- Room cards for Standard Room, Deluxe Room, and Luxury Suite
- Sample room tariffs and amenities
- Hotel facilities such as Wi-Fi, swimming pool, restaurant, parking, fitness center, and room service
- Guest reservation details form

**Note:** The displayed room rates are sample prices. The interface is a demonstration and does not check live room availability.

## 3. Vibrance 2026 College Fest Website

**Purpose:** To share information about a college festival and allow students to submit a sample event registration.

### Main Features
- Festival landing page and navigation menu
- Event categories: technical events, cultural events, and workshops
- Event schedule with time, event, and venue
- Event coordinator details
- Fest rules and participation reminders
- Event registration form with name, email, college name, and event selection

## How to View

1. Keep each website's HTML, CSS, JavaScript (if used), and image assets together in its project folder.
2. Open the relevant `index.html` file in a web browser, or run the project using your preferred local development server.
3. For the hotel and festival forms, use the interface as a demo unless a backend and database have been connected.
